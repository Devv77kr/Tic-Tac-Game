# Tic-Tac-Game
Tic‑Tac‑Toe is a two‑player, turn‑based paper-and-pencil game played on a 3×3 grid. Players alternate placing their mark (X or O) in empty cells. The first player to place three of their marks in a straight line (horizontal, vertical, or diagonal) wins. If all nine cells are filled without either player forming such a line, the game is a draw.
